# Presentation source (review deck)

The 13-slide review deck is hosted as an online slide artifact (Slides type): `https://claude.ai/artifact/6GjZ4xAX55LWVnJmNL68gj` (artifact id `2ab012f2-065e-499e-b671-af9633845c94`; private, shared from the page's Share menu).
This folder keeps a local copy of its source (`deck.json` = slide order, `slides/*.html` = one slide each, with speaker notes) so the content is preserved with the project. The HTML uses the Slides runtime's own subset (fixed 1920 x 1080 canvas); it is not a stand-alone web page and is not a `.pptx` file. To obtain a PowerPoint or PDF file, open the artifact and use its download menu.
Every number on the slides comes from `docs/STAGE3_CONFIRMATION_RESULTS.md` and `stage3/results/summary_s3_heldout.md`.
