TimSort's rule

With 3 distinct values it can need n log n comparisons (shown in the paper).

Theory only

Cheap keys

Streak-Adaptive Galloping for Natural Merge Sort

7 / 13

Four gaps. First, the safe rule fixes t per merge and never learns from the streaks it sees. Second, TimSort's own adaptive rule can be fooled. Third, the paper has no code and no timing results, so nobody had measured whether fewer comparisons give less time. Fourth, in our Stage 1 measurements with cheap integer keys, even galloping itself was slower than a plain merge.
