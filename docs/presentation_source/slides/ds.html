Data Structures Used

Array

The input list. It is sorted in place.

Stack of runs

Waiting sorted runs (start, length). A rule picks which two to merge.

Temporary buffer

A copy of the smaller run while merging. At most n/2 items.

String record

{pointer, length, index}. Lets us sort strings; the index checks stability.

Plus counters that count every comparison, switched on only for measurement.

Four structures. The array is the input. The stack holds runs waiting to be merged. The temporary buffer holds a copy of the smaller run, so at most half the array. For strings we sort small records that point to the text and carry the original index, which lets us check that equal keys keep their order.
