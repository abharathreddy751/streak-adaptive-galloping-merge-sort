Algorithm Used: Natural Merge Sort

1

Find runs

Cut the list into parts that are already in order.

2

Pick runs

A stack rule (PowerSort or TimSort) chooses two neighbouring runs.

3

Merge

Copy the smaller run to a buffer, then do a stable two-way merge.

4

Gallop

Check t items one by one, then jump 1, 2, 4, 8… and binary-search back.

5

Set t

Paper's rule: t = ceil(log2(a+b))^2, fixed for the whole merge.

Stable: equal items keep their original order (ties go to the left run).

Streak-Adaptive Galloping for Natural Merge Sort

4 / 13

Walk through the five steps. A run is a part of the list that is already sorted. When two runs are merged, the output comes in streaks from one run. Galloping finds the end of a streak with few comparisons. The number t says how many items to check one by one before jumping. The base paper fixes t for the whole merge; that is the part we try to improve.
