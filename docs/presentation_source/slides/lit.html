Streak-Adaptive Galloping for Natural Merge Sort

6 / 13

Three pieces of background. TimSort is the sort inside Python, Java and V8. PowerSort is another natural merge sort that chooses the merge order carefully. The base paper, published in Algorithmica in 2025, shows that TimSort's own rule for galloping can be fooled: with only 3 distinct values it can need n log n comparisons. It proposes a safe rule that gives n plus n log sigma for sigma distinct values. The paper is theory only; our code is our own re-implementation, not the authors' code.
